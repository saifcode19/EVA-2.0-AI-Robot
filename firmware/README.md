# EVA 2.0 Firmware

This directory contains the firmware and hardware-specific modifications developed for the EVA 2.0 AI voice assistant robot.

The firmware is based on the open-source XiaoZhi ESP32 framework and has been customized for the EVA 2.0 hardware platform.

## Hardware Integration

The firmware is configured for:

- ESP32-S3
- INMP441 digital microphone
- MAX98357A I2S audio amplifier
- SPI display
- Servo motors
- GPIO and PWM peripherals
- Wi-Fi connectivity
- MCP-based device control

## Firmware Work

The custom implementation includes:

- Hardware-specific configuration
- Servo control
- Display integration
- Audio input/output configuration
- GPIO/PWM control
- MCP device-control integration
- Hardware debugging and testing
